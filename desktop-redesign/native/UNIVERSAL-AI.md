# ALEC 0.3.3 — Universal AI & Skills Engine
Original implementation, not a bundled Free-LLM router. Provider endpoint presets based on a reviewed public catalog (nejib1/Free-LLM, MIT, 6a037e05f186b392e31c5cde4b2837501d4b4bbb); no copied source or credentials. OpenRouter Free obtains the official public catalog, filters exact :free model IDs and zero advertised pricing, treats capabilities as text-only, verifies selected ID before a turn and refuses if unavailable. Free quotas, billing terms and real provider authentication are not guaranteed; other presets may incur costs. Keys use existing native auth storage. Single-model routing defaults on; new parallel agents and automatic model fallbacks disabled, including scheduled AI agents; user can opt out except when Free selected. This does not unload external models or cancel already running work. Hosted compatibility endpoints are treated as cloud for the new adaptive memory context; upstream history/facts are governed by existing provider behavior. Six curated prompt recipes prepare the Ask box; user reviews and sends. Existing Skill Hub stays intact; no plugin execution or new tool permissions. Windows and actual provider integration must be tested; no user credentials used in CI.
