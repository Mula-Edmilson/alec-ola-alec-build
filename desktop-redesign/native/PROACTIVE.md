# ALEC 0.3.2 — Proactive Intelligence
Read-only, local system telemetry and opt-in background monitoring. CPU sampled over 300ms, RAM from OS, free space on home volume, battery via Windows power API, manual top five processes by working set. Optional foreground process name only, clipboard sequence and format only (no clipboard contents). Background samples every 60s while idle; no model calls; desktop text alerts, two consecutive CPU/RAM pressure samples, battery <=15% unplugged, clipboard change; global 2-minute and per-category 15-minute cooldown. Settings persist; snapshots and last five alerts in memory only. No process termination, no screenshots, no recording, no remote relay, no auto-action. Sampling may miss short events, Windows metrics may be unavailable, no actual user-hardware performance claim. Manual scan works with monitoring disabled. Existing signed updater retained. Windows CI tests required before publication.
