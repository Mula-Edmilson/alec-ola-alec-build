# ALEC 0.3.1 — Adaptive Memory & Personality
Original implementation; no Brahma code. Six persistent response-style controls, explicit 'memoriza que …' requests intercepted before model calls, local review queue, 100 bounded records, category/search, disable and delete. Relevant approved context capped at 320 characters plus header; cloud providers opt-in, remote-origin and Claude Code CLI excluded from new retrieval. Local provider may point to a remote server; do not store secrets. No encryption, no automatic inference of private details, no background monitoring, no autonomous actions, no migration or deletion of upstream memory/history. Removing a record does not remove copies already present in history or sent to a provider. User data is stored in a distinct per-user file. Existing three personality presets, Orb Evolution and signed updater retained. Windows validation required before publication.
