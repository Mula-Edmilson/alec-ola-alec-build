# ALEC 0.3.0 — Orb Evolution
Original Canvas2D projected-3D renderer, based on the local ALEC visual prototype. No Brahma assets or source, no external runtime, no additional model. Shared with the panel and notch; native overlay stays transparent and keeps existing click, position, voice and introduction plumbing. Compact desktop radius capped at 72 CSS px, preserving small/cursor choices. This is a test candidate; Android, Orb Vision and actual Windows user hardware are not validated. Signed update pipeline is unchanged; no release until candidate validation and separate publication.
